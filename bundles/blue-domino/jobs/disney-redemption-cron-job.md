# Disney Redemption File Upload Cron Job

## Summary

The Disney Redemption File Upload Cron Job is an automated scheduler that monitors designated directories on a dedicated VM for new Disney redemption files and uploads them to Disney's external server via API. This job eliminates the need for manual coordination between the Offers Team and Domino Team by automating the file transfer process on a scheduled basis.

## Details

### Purpose

The cron job automates the upload of Disney redemption files (`kroger-*-redeemed-codes.csv`) generated by the Offers Team to Disney's external server, reducing manual intervention and improving operational efficiency.

### Schedule Configuration

The cron job schedule is determined based on the file generation frequency provided by the Offers Team. Specific timing details should be coordinated between teams.

### Script Functionality

The automated script performs the following operations:

- Monitor `/disneyData/incoming/` for new files matching the pattern `kroger-*-redeemed-codes.csv`
- Validate file format and contents
- Upload files to Disney server via API
- Verify successful upload using Disney list directory API
- Move successfully uploaded files to `/disneyData/processed/`
- Move failed uploads to `/disneyData/failed/`
- Generate detailed logs for Dynatrace monitoring
- Prevent duplicate uploads through checksum tracking

### Execution Environment

The job runs within a restricted local user account (`disney-upload-user`) created specifically for this automated process. The user account is configured with:

- Limited shell access (`/bin/bash` with restricted permissions)
- No sudo access or elevated privileges
- Directory restrictions limiting access to `/disneyData/incoming/` only

### Monitoring and Notifications

Job completion and failure events are monitored through Dynatrace log alerts, notifying relevant teams of upload status and any errors requiring intervention.

### Integration with File Upload Process

The cron job operates within a broader workflow where the Offers Team:

1. Generates redemption files locally
2. Connects to the VM using SFTP/SCP with provided credentials
3. Uploads files to the designated directory
4. Monitors alerts for job completion/failure
