# Disney Redemption File CSV Format

## Summary

The Disney Redemption File CSV Format defines the structure and naming convention for redemption files generated by the Offers Team and uploaded to Disney's external server as part of the automated file upload process. Files follow the naming pattern `kroger-*-redeemed-codes.csv` and contain redemption code data in comma-separated values format.

## Details

### File Naming Convention

Files must follow the pattern:
```
kroger-*-redeemed-codes.csv
```

Where the asterisk (*) represents a variable portion of the filename determined by the Offers Team's file generation process.

### Format Specification

- **Format Type**: CSV (Comma-Separated Values)
- **File Extension**: `.csv`
- **Content**: Redeemed codes and redemption data
- **Character Encoding**: Unknown
- **Line Endings**: Unknown
- **Delimiter**: Unknown (standard CSV assumed)
- **Quote Character**: Unknown
- **Escape Character**: Unknown

### Content Validation

The automation script validates both file format and contents before upload to Disney's server. The specific validation criteria and CSV schema (column names, data types, required fields, field order) are Unknown.

### Processing Requirements

- Files are placed in designated directories for automated upload (`/disneyData/input/` or `/disneyData/incoming/`)
- Format consistency is assumed across all generated files
- Successfully uploaded files are moved to `/disneyData/processed/`
- Failed uploads are moved to `/disneyData/failed/` for review
- Duplicate uploads are prevented through checksum tracking
